# Luminal — color system

The palette is role-based. Keep the environment quiet so the light path remains the focal point.

| Token | Hex | Role |
|---|---|---|
| Ink | `#070D10` | Main background |
| Deep | `#0D171A` | Lower environmental layer |
| Slate | `#263A3B` | Grid and structural surfaces |
| Jade | `#8FB8A1` | Destination / resolved state |
| Brass | `#D4A66A` | Emitter / primary action / reflector |
| Paper | `#E8E4D7` | Primary type and beam core |
| Sage | `#8D9A91` | Secondary type |

## Application rules

- Ink and Deep occupy most of the screen.
- Slate is structural, never a competing highlight.
- Brass marks the source and primary action.
- Jade marks the destination and successful state.
- Paper is reserved for readable type and the beam's brightest core.
- Avoid gradients as a default surface treatment and avoid adding accent colors without a gameplay meaning.
