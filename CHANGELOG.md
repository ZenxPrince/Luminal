# Changelog

## Luminal — visual identity revision

- Renamed the Godot application and project identity from ECHO to Luminal.
- Reworked the title and completion screens with a mineral-dark optical-lab atmosphere.
- Replaced the purple/blue/neon palette with ink, slate, sage, jade, warm brass and paper.
- Reassigned gameplay colors by role: brass source, pale beam, jade destination, champagne reflectors.
- Reworked button surfaces, typography colors, interface labels and the application icon.
- Updated README, project structure notes and palette documentation.
- Preserved the five-level puzzle progression, controls, reflector behavior and scene flow.
