# Luminal

**A signal stuck in a loop. Place reflectors. Escape.**

Luminal is a compact optical puzzle game about redirecting light, manipulating mirrors and finding paths through increasingly complex environments.

<p align="center">
  <strong>5 Levels · Optical Puzzles · Mirror Mechanics · Godot</strong>
</p>

## The Experience

You are a signal emitted from a source. Walls block your path. Your objective is to position reflectors and guide the beam into its destination.

Every placement changes the trajectory. Observe, experiment and find your way through.

## Features

- Five handcrafted puzzle levels.
- Interactive mirror placement and rotation.
- Two reflector orientations.
- Light-beam trajectory and collision mechanics.
- Atmospheric dark visual design.
- Compact gameplay experience of approximately 3–5 minutes.

## Levels

| Level | Name | Challenge |
|---|---|---|
| 01 | First Light | Learn the fundamentals |
| 02 | Deflection | Navigate an L-shaped obstacle |
| 03 | Split | Find a route to either exit |
| 04 | The Loop | Navigate an enclosed corridor |
| 05 | Escape | Solve the final arrangement |

## Controls

| Input | Action |
|---|---|
| Left Click | Place or rotate reflector |
| Right Click | Remove reflector |
| TAB | Switch reflector orientation |
| R | Reset current level |
| ESC | Return to menu |

## Run Locally

1. Install [Godot Engine 4.3 or newer](https://godotengine.org/download/).
2. Clone this repository.
3. Open the project file:

   ``text
   project/project.godot
   ``

4. Import the project.
5. Press **F5** to run.

No separate runtime libraries are required beyond Godot for editor-based execution.
